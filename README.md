# BES-SIM2

This repository contains all scripts and datasets used for the analysis and figures for the second Biodiversity and Ecosystem Services Scenario Inter-Model comparison (BES-SIM 2)

This repository, and its releases be will be available to download from Zenodo.

The BES-SIM 2 project files are stored in in the i: drive following `i:\biocon\Projects\BES-SIM 2\`.

Within this folder there is a README containing the folder structure and and other relevant information for proper storage, tractability and replication.

## Land use datasets.

Raw data sets include: 1) land use projections; 2) protected area maps; and 3) land use intensities for agriculture and forestry.

Two (three in the coming weeks) have submitted their land use projections as part of BES-SIM 2 and will be available in the following links:

| ID | Title | DOI | Resolution | Status |
|--------------|----------------|--------------|--------------|--------------|
| 88 | Land Use projection (BES-SIM 2 GLOBIO) | to be produced | 10 arc seconds | in progress |
| 89 | Land Use projection (BES-SIM 2 PLUM) | to be produced | 0.01 degrees | finished |
|  | Downscaled Land Use projection (BES-SIM 2 GLOBIO) | to be produced | 0.5 degrees | not initiated |
|  | Downscaled Land Use projection (BES-SIM 2 PLUM) | to be produced | 0.5 degrees | not initiated |

In addition, two downscaled aggregated versions of PLUM and GLOBIO are provided.

A third data set from the modelling team at PIK using MAgPIE-REMIND model is also expected to be shared with the modelling teams.
